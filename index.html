Privacy by architecture

Your documents never leave the device

There is no backend to send files to. PDFs you open are decoded in memory, and only documents you explicitly save are kept in this browser's IndexedDB — delete them any time from the Library.

  • ✓ No accounts, no analytics of document content
  • ✓ No hidden uploads or cloud sync
  • ✓ Remote PDFs load only from servers that allow it
  • ✓ PDFs never run JavaScript inside the viewer

Install it as an app

Add Luma PDF to your home screen or desktop. Saved documents open offline, and the interface shell is cached by a service worker.

Open library

Android and desktop browsers show an install prompt; on iOS use Safari's Share → Add to Home Screen.
