About

A PDF workspace that trusts your device

Luma PDF exists because most PDF sites ask you to upload a private document to a server you know nothing about. This one cannot — there is no server.

What it is

A complete, static PDF application: reader, annotator, page organiser, 39 conversion, cleanup and security tools, and an embeddable viewer for websites. Everything runs in the browser tab you have open. Nothing is transmitted, and nothing needs an account.

Privacy, concretely

  • No uploads. Files are read with the File API into memory; PDF.js decodes them locally.
  • Local storage only. Documents you save go into this browser's IndexedDB. Delete them from the Library or Settings at any time.
  • No tracking of content. There is no analytics script, no telemetry, no remote logging.
  • Remote PDFs are fetched straight from the host you name, with the browser's normal origin rules — Luma PDF never proxies them.
  • No PDF JavaScript. The engine is configured with isEvalSupported: false, so scripts inside a document never run.
Because there is no backend, "your data" means "this browser's storage". Clearing site data, using private windows, or switching devices means starting fresh — that is the trade-off for local-only processing.

PDF.js, pdf-lib and qpdf are vendored in vendor/ so the app works offline. The only runtime download is the OCR engine, which is fetched the first time you run OCR — the document itself never leaves the device. The interface, design system and all application code are original.

What it deliberately does not do

  • No public CORS proxy — that would undermine origin security for every site.
  • No DRM claims. Hiding a download button does not stop a determined reader.
  • No fake features: every button in this build performs a real action, and anything unsupported says so.
  • No OCR bundled by default; scanned pages without a text layer are reported honestly.

Built for modest hardware

Rendering is virtualised, canvases are capped by a pixel budget, and memory is released as you scroll. On a 3 GB Android phone the Eco profile keeps a document readable instead of crashing the tab — the same profile that renders this page.
